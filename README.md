# Sách nhà Harry – trang web

Trang web của kênh TikTok @sachnhaharry: bài học mỗi ngày, trắc nghiệm tâm lý và blog.

- Trang web là các file ở thư mục gốc (`index.html`, `bai-viet/`).
- Nội dung bài viết nằm trong `_src/articles.py`. Sau khi thêm bài, chạy `python3 _src/build.py` để tạo lại trang.
- Netlify tự cập nhật trang mỗi khi có thay đổi mới trên nhánh chính.
